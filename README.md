## 📖 Overview

Healthcare Inventory Optimization System is a smart inventory management platform developed to assist hospitals and healthcare organizations in efficiently managing medical supplies while staying within budget constraints.

The system leverages **Subset Sum** and **Backtracking Algorithms** to identify optimal combinations of medical supplies, helping administrators make data-driven procurement decisions.

---

## ✨ Key Features

### 📦 Inventory Management

* Manage healthcare inventory records.
* Monitor stock availability in real-time.
* Track medical equipment and consumables.

### 💰 Budget Optimization

* Optimize procurement within a given budget.
* Select the best combination of supplies.
* Reduce inventory wastage and overspending.

### 🚨 Low Stock Alert System

* Automatically identifies critical stock shortages.
* Highlights supplies requiring immediate replenishment.
* Supports proactive inventory planning.

### ⚡ Emergency Priority Mode

* Prioritizes essential healthcare supplies.
* Supports emergency procurement scenarios.
* Enhances hospital preparedness.

### 📊 Analytics Dashboard

* Inventory summary statistics.
* Optimization efficiency metrics.
* Budget utilization monitoring.
* System health indicators.

### 🧠 Intelligent Optimization Engine

* Subset Sum Algorithm
* Backtracking Algorithm
* Combination-based decision support
